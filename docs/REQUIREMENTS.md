# Требования и исходные сведения

## Подтверждено пользователем

- Тема: «Разработка информационной системы для организации пропускного режима в организации на базе платформы 1С:Предприятие».
- Организация: ООО «ЧРЗ», https://chrz.ru/.
- Аккаунт проекта №4: `marko000007`.
- Рабочая папка: `ГИТЫ/4 - marko000007` на рабочем столе.
- Отдельная цель: минимум 50 содержательных коммитов; первоначальная загрузка не заменяет завершённые итерации. Ориентир общего числа — 55–60.
- Включение в общий планировщик №1 → №2 → №3 → №4 с текущим сроком до 24.11.2026 включительно.

## Рабочая архитектура

Python / Django отвечает за веб-интерфейс и кабинеты. Конфигурация 1С отвечает за предметные справочники, жизненный цикл пропуска, проверки допуска и регистр посещений. Интеграция — через HTTP-сервис 1С с JSON; прямую запись Python в таблицы информационной базы не использовать. Сохраняются рабочие формы в самой 1С для проверки и демонстрации. Это выбранное направление разработки; соответствие учебному заданию и доступность среды ещё проверяются.

## Предварительно предложено

Учёт заявок и пропусков, согласование, контроль срока действия и отзыва, регистрация посещений, разграничение доступа, отчёты и печать пропуска. Это проектные предложения, а не сведения о действующей системе предприятия.
