# Среда разработки №4

Найдена учебная 1С:Предприятие 8.3.27.1606 для macOS. Исполняемый файл: /Applications/1cv8t.localized/8.3.27.1606/1cv8t.app/Contents/MacOS/1cv8t; пакетные команды запускаются с cwd его каталога. Создание отдельной файловой базы и выгрузка пустой конфигурации реально прошли 22.11.2026. База в .local/1c/development исключена из Git; исходники XML — one_c/configuration.

Учебная версия ограничивает объём данных и число сеансов, не поддерживает клиент-серверный режим и пароли пользователей; печать ограничена Конфигуратором. Она подходит для разработки учебной конфигурации; реальную промышленную публикацию и проверку защищённого HTTP-сервиса на ней нельзя считать выполненными. Источник: https://v8.1c.ru/podderzhka-i-obuchenie/uchebnye-versii/distributiv-1s-predpriyatie-8-3-versiya-dlya-obucheniya-programmirovaniyu/ .

Python-портал использует отдельную техническую БД авторизации. Бизнес-данные в ней не дублируются. Проверка Python с HTTP-имитатором учитывается отдельно от запуска и проверки модулей 1С.
