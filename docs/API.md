# Контракт локального обмена v1

Текущий исполнитель HTTP — локальный адаптер, делегирующий каждый предметный вызов настоящему процессу1С через приватный фиксированный RPC. Архитектура и границы — ARCHITECTURE.md; команды первого запуска — LOCAL_ERP.md.

Ответ200 содержит `api_version:1` и `data`. Роль берётся из действующего PortalUsers. Заголовок X-Portal-Actor содержит UTF-8 логин вBase64, сформированный Django; HTTP требует служебный Basic-ключ. Браузер не получает этот ключ. POST требует UUID Idempotency-Key и JSON-объект до128КиБ. Ответ ограничен1МиБ. Redirect отклоняется, loopback Host/Origin проверяются.

| Метод/маршрут | Результат или тело |
| --- | --- |
| GET /health | system=1c-enterprise, status=ok |
| GET /actors/me | actor/role |
| GET /references | visitors/employees/checkpoints/purposes, до500 каждого |
| GET /requests | Последние100 доступных заявок |
| POST /requests | visitor_id,host_id,checkpoint_id,purpose_id,starts_at,ends_at |
| POST /requests/approve, /reject, /cancel | id,expected_status,reason |
| GET /passes | Последние100 доступных пропусков |
| POST /passes | request_id |
| POST /passes/revoke | id,reason |
| POST /movements | pass_id,checkpoint_id,direction(in/out) |
| GET /events | Последние100 доступных событий |

Даты ISO8601 с часовым поясом, до секунды. Решение/пропуск/проход проверяются1С, автор/время задаются сервером. Заявитель получает свои строки, guard — согласованные заявки; переходы и ограничения описаны в PASS_RULES.md.

400 — подтверждённый отказ параметрам/условиям;403 — доступ;409 — конфликт ключа/состояния;503 — результат исполнения не подтверждён. При неизвестном ответе портал сохраняет прежний UUID и подготовленные параметры. Журнал1С хранит actor+UUID+SHA256 команды/точного тела+ответ атомарно с изменением. Техническая очередь подтверждений портала защищает одинаковый контекст от изменённого повтора и запоздалого удаления.

scripts/verify_erp.py проверяет реальный HTTP→1С в отдельной отмеченной базе. Транспортные тесты с заглушкой имеют отдельные названия и не заменяют эту проверку. Нативный HTTP-сервис1С и его многопользовательская аутентификация остаются открытыми; работа текущего адаптера подтверждена отдельно.
