# Локальный запуск

1. Откройте корневую папку проекта в Python IDE.
2. Создайте виртуальное окружение Python 3.12+ и установите зависимости:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

3. Выберите `.venv/bin/python` как интерпретатор проекта.
4. Откройте `run_local.py` и нажмите Run. Параметры запуска не нужны.

Из терминала:

```sh
.venv/bin/python run_local.py
```

Адрес приложения: http://127.0.0.1:8044 . Остановка — Stop в IDE или Ctrl+C. Сервер запускается одним процессом и доступен только на этом компьютере. Рабочий каталог устанавливается автоматически, поэтому запуск файла из другого каталога не меняет расположение данных.

Проверка подготовки без сервера:

```sh
.venv/bin/python run_local.py --check
```

Полный первый запуск с установленной 1С: `.venv/bin/python run_local.py --setup-demo --check`. Начальные пароли вымышленных аккаунтов находятся в `.local/demo-accounts.json`; последующие запуски выполняются без этого флага.

Перед стартом автоматически применяются локальные миграции и выполняется проверка Django. По умолчанию используется SQLite. Если DATABASE_URL уже задана, она должна указывать на локальный PostgreSQL; удалённая база этим способом не изменяется. Файл .env автоматически не читается, переменные задаются в настройках запуска IDE или терминале.

Предметные данные и команды хранятся в 1С. SQLite содержит вход, сессии и технические неподтверждённые команды. Установленная платформа вызывается локальным адаптером; он автоматически запускается вместе с порталом. Настройка и ограничения — [LOCAL_ERP.md](LOCAL_ERP.md). Пользовательский цикл — [USER_GUIDE.md](USER_GUIDE.md).

Если стандартный порт занят другим процессом, оставьте его работающим и выберите другой: `python run_local.py --port 8121`. Параметр можно задать и в конфигурации запуска IDE.
