# Пропускной режим на платформе 1С:Предприятие

Тема: «Разработка информационной системы для организации пропускного режима в организации на базе платформы 1С:Предприятие».
Организация проекта: ООО «ЧРЗ».

Заявка → согласование → выдача пропуска → вход и выход → журнал. Есть отмена заявки, отзыв пропуска, проверка срока и точки прохода, защита повторной отправки. Заявитель, согласующий, сотрудник проходной и администратор получают разные права. Предметные данные и правила исполняются в настоящей 1С; Python предоставляет интерфейс и техническую очередь подтверждений.

## Первый запуск

Python 3.12+ и установленная учебная 1С 8.3.27.1606:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run_local.py --setup-demo --check
.venv/bin/python run_local.py
```

Откройте http://127.0.0.1:8044 . После однократной подготовки в IDE достаточно выбрать `.venv/bin/python` и нажать Run в `run_local.py` без параметров. Остановка — Stop или Ctrl+C.

Подготовка создаёт вымышленные данные и недостающие аккаунты `demo.admin`, `demo.requester`, `demo.approver`, `demo.guard`. Начальные случайные пароли новых аккаунтов сохранены только в `.local/demo-accounts.json` с правами 0600. Существующие учётные записи не перезаписываются. Для обычной работы используется отдельный локальный HTTP-адаптер, запускаемый вместе с порталом. Особенности установленной платформы — [docs/LOCAL_ERP.md](docs/LOCAL_ERP.md).

```sh
.venv/bin/python main.py test tests
.venv/bin/python scripts/verify_erp.py
```

[Руководство пользователя](docs/USER_GUIDE.md) · [правила пропусков](docs/PASS_RULES.md) · [локальная приёмка](docs/ACCEPTANCE.md).

Исходники конфигурации находятся в `one_c/configuration`, схема — `one_c/schema.json`. Правила учебные; соответствие внутреннему регламенту организации не подтверждено. Нативный HTTP-сервис и многопользовательская аутентификация платформы, обслуживание остальных справочников и оставшиеся критерии перечислены в [docs/PROGRESS.md](docs/PROGRESS.md).

Доступны карточки решения и отзыва, печатный информационный лист, полный ограниченный периодный журнал/CSV и добавление посетителя администратором через1С. Посетители выбираются по организации/ID. Новая локальная приёмка — [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md).
