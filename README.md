# Пропускной режим на платформе 1С:Предприятие

Тема: «Разработка информационной системы для организации пропускного режима в организации на базе платформы 1С:Предприятие».
Организация проекта: ООО «ЧРЗ».

Python/Django отвечает за веб-портал, 1С — за предметные данные и правила. Сценарий проекта: заявка → согласование → выдача пропуска → вход и выход → отчёт. Правила проектные; соответствие внутреннему регламенту организации ещё требует проверки.

Работают вход, проверка прикладной роли, форма и список заявок. В локальной учебной 1С 8.3.27.1606 проверены шесть справочников, политика доступа и документ заявки. Согласование, выдача пропуска, проход и сквозная локальная HTTP-связь с 1С ещё разрабатываются. Транспортные тесты Python используют имитатор и не заменяют реальную интеграцию.

## Запуск портала

Python 3.12 или новее:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run_local.py --check
.venv/bin/python main.py createsuperuser
.venv/bin/python run_local.py
```

Команда `--check` подготовит локальную техническую базу. Пароль вводится интерактивно. Откройте http://127.0.0.1:8044 . В IDE выберите `.venv/bin/python` и нажмите Run в `run_local.py` без параметров. Остановка — Stop или Ctrl+C.

Предметные записи хранятся в 1С; SQLite портала содержит только техническую авторизацию и сессии. Для интеграции задаются `ERP_BASE_URL`, `ERP_USERNAME`, `ERP_PASSWORD`. При отсутствии локального сервиса портал показывает недоступность. Подробности — [docs/LOCAL_RUN.md](docs/LOCAL_RUN.md), сборка конфигурации — [docs/BUILD_1C.md](docs/BUILD_1C.md).

```sh
.venv/bin/python main.py test tests
.venv/bin/python scripts/one_c.py --help
```

Исходники конфигурации находятся в `one_c/configuration`, модель — `one_c/schema.json`. Прогресс — [docs/PROGRESS.md](docs/PROGRESS.md).
